# 寵物路線圖：阿居畫圖 → 切圖

- `prompts.py <路線代號>`：印出給阿居（ChatGPT）的畫圖指令（一張圖＝少年／勇者／傳說三隻並排，附上 `img/<寵物>_1.png` 當參考圖）。
- `cut.py`：把截下的兩段畫面（上半、下半）拼回 1536×1024 → 去白底 → 切成三隻 → 存 `<路線>_2/3/4.png`（512×512 透明背景）。
  - 預設用腳的位置自動分三隻；分錯時用 `SEEDS="x:y;x:y;x:y"`（拼好後的座標）手動指定三隻身體位置。
- 圖放進 `img/` 後，要在 `index.html` 的 `ART` 加檔名才會顯示（SUNNY 看過 OK 才加）。
